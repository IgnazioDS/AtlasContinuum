# Notices and provenance

## Atlas Continuum

Atlas Continuum's original additions include the independent package identity,
Retail quest-position bridge, live coverage audit, project documentation,
validation tests, packaging scripts, and development installer. Those changes
are released under the same MIT terms as the runtime code.

## OpenMap

This project contains and modifies OpenMap `v0.7.1-beta-retail`, downloaded from
its public CurseForge release on 22 October 2026.

OpenMap runtime code is licensed under the MIT License:

> Copyright (c) 2026 OpenMap contributors

The original copyright and full license are preserved at
`AtlasContinuum/LICENSE.txt`. Bundled Ace3 components retain their notices in
`AtlasContinuum/LICENSES/`. Atlas Continuum must not be described as wholly
original code; public listings should identify it as an independent OpenMap
fork.

## World of Warcraft assets

The MIT license covers code, not Blizzard map art. The Retail texture directory
contains masks cut from World of Warcraft map art and textures generated from
noise. Their upstream provenance is preserved in
`AtlasContinuum/Media/Textures/Retail/NOTICE.md`.

Before public redistribution, confirm that packaging these derived assets
complies with Blizzard's current UI Add-On Development Policy and platform
terms. This notice documents provenance; it does not grant rights to Blizzard
assets or trademarks.
